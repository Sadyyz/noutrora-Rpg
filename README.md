# noutrora-Rpg
Noutrora RPG  Noutrora é um RPG de texto feito em Python com elementos de terror, suspense e exploração.  Você assume o papel de um aventureiro do vilarejo de Stormcloak, que decide explorar a misteriosa masmorra conhecida como Noutrora em busca de riquezas, respostas e sobrevivência.
